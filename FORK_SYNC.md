# Сопровождение форка

Upstream: [carthage-software/mago](https://github.com/carthage-software/mago), основная ветка `main`. Форк: [Teletype-App/mago](https://github.com/Teletype-App/mago), основная ветка `teletype`. Текущая upstream-база: `1.51.1`.

## Контракты throws-анализа

Для исходников проекта вычисляй исключения из тел, для зависимостей используй объявленные контракты. Сохраняй межфайловой inference, условия аргументов, callbacks, генераторы, catch/rethrow/finally и разрешимые Yii 2 hooks.

Неизвестные эффекты не дают удалять или сужать существующие `@throws`. Правки должны сохранять описания, прочие аннотации и форматирование. Git-отбор ограничивает отчёт и правки, не расчёт сводок. Кэш проверяет содержимое и зависимости, при изменении сериализации или семантики обновляй его схему.

Ближайшие проверки находятся в `crates/analyzer/tests/throws_docblocks.rs`, сценариях `throws_*` и `tools/throws/test_cli.py`. Используй изолированные PHP-примеры и проверки, относящиеся к изменению.

## Синхронизация

Интегрируй проверенную стабильную базу настоящим merge с upstream. Сохраняй возможности форка, упаковку и CI. Изменение архитектуры анализатора требует отдельной проверки точек интеграции. Обновляй README по итоговому поведению.

## Версии и публикация

Релиз имеет формат `<upstream-version>-pN`. Для одной базы увеличивай N, при новой базе начинай с p1. Тег, версия корневого Cargo package и `extra.mago-binary-version` должны совпадать. Workspace crates сохраняют upstream-версию. Сравнивай pN численно, учитывай прежний формат patch.N и не полагайся на порядок GitHub Releases.

Composer-пакет называется `teletype/mago`, постоянное ограничение `^1.51`. Composer install использует lock-файл, update выбирает совместимый релиз. Загрузчик и self-update обращаются к этому форку.

`.github/workflows/cd.yml` публикует семь бинарных архивов после успешного CI на том же коммите. Docker images и crates не публикуются. Новые теги и релизы требуют запроса пользователя. Описания релизов должны содержать только публичные изменения продукта.
